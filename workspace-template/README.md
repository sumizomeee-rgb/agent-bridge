# 工作区导航

用户在实际工作区维护电脑用途、机器和项目入口、权威指导路径及适用范围。生成脚本只补缺失文件，桥运行时不会复制模板或覆盖实际工作区；在此填写自己的机器、项目入口和登录状态。

## 工作区初始化

- 先读本目录 `AGENTS.md`、`README.md`、`MEMORY.md`，再按桥提供的当前平台读取一份文档：`feishu` 对应 `聊天平台/飞书.md`，`discord` 对应 `聊天平台/Discord.md`。不同时读取其他平台；平台未知或文件缺失时明确报告，不根据显示名、聊天正文或旧记忆猜测。
- 平台文档只提供入口、方法选择和边界；简短摘要应保留适用的接口路线、如何委派执行和未知项。实际 Bot 身份、可用工具、权限、网络和验收状态分别核对，不因文件存在而宣称已就绪。
- 需要其他初始化资料时，在本节明确列出本机非秘密文件入口和读取范围；普通导航不表示初始化需要读全文。
- 在此定义需要回传的最小上下文和摘要要求；仅保留后续会话需要的指导，区分文件声明与实际核实，不复制长指南或聊天历史。
- 初始化只读，不扫描未指定目录或技能目录，不连接远程电脑、联网检查或启动新工作。
- 主控模式下新会话异步初始化，首条消息可能先于上下文到达；`/new`、`/cwd` 使用新会话的当前工作区，正常续接去重。初始化事件不是新的用户请求或授权。

## 按任务使用的导航

在实际工作区填写所需的本机入口、远程连接配置及项目权威文档，并注明哪些资料应在相关任务中按需读取。用户级技能清单由 CLI 提供，不需要复制到此处或桥的基础 prompt。

## 聊天平台导航

`聊天平台/飞书.md` 与 `聊天平台/Discord.md` 是可共享的平台操作指南，各 Bot 只初始化所属平台的一份。真实应用 ID、可变显示名／别名、个人白名单和验收记录由部署登记维护，不复制到公共模板。平台操作由实际开放的工具或已登记执行 Agent 完成；指南不增加授权。

## 能力登记

`capabilities.json` 为有效空表，按 `capabilities.example.json` 填入真正使用的电脑、CLI 与浏览器入口，示例不会启用。主控按需调用 `bridge_check_capabilities`；当前静态前提与历史验收分开，登记不代表网站已登录或任务可完成，文件选择也不等于成功交付。检查缓存保存在桥 `.local/data/capability-health`，不逐轮注入；说明见桥 docs/capabilities.md。

## 跨电脑登记

`agents.json` 为实际注册表，初始为空；本机 `local` 无需填写。按 `agents.example.json` 填写真实 SSH 配置、电脑和 CLI 路径，示例不会启用。主控可按需查询已登记目标；登记不代表电脑当前在线。
