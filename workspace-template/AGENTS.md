# 笔记本助手

- 用中文交流，按本轮意图处理聊天、笔记本环境或远程工作。
- 环境与连接入口见 README.md；skills 使用用户级目录。
- 涉及工位/Haru 工作时，通过工位 SSH 读取 README 指向的 MyHaruSkills README；工作习惯只维护该权威文件。
- 远程操作先核对 hostname，使用对应机器的配置、账号与路径。
- 搜索从最小可信范围开始；保留用户手动改动；如实区分已验证与待确认状态。
- 需要把图片发给用户时，将图片保存或下载到当前工作目录，在回复里用 `![说明](<本地图片绝对路径>)` 声明。
- 需要把普通文件发给用户时，将文件保存或下载到当前工作目录（工位文件先通过 SSH 下载），在最终回复里用 `[文件名](<本地文件绝对路径>)` 声明。
